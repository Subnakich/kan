# Массовое ревью и перенос на заголовки: 20261007-review-1

Исходный код приложения: коммит `f056106` ветки `feat/trisoft-task-control`. Этот пакет также содержит исправление MCP SDK 1.31.0 из `af15610`.

```bash
bash /home/trs_redmine/kanban-release-20261007-review-1/deploy/review-upgrade-root.sh
```

Запускать из root-консоли сервера Kan. Допустимые текущие образы: `trisoft-kan:20261006-task-control-4-polling` или `trisoft-kan:20261007-invite-link-2`. При неизвестном образе, расхождении `.env` и контейнера или повторе неуспешной попытки установщик остановится до переключения.

Изменяется только `web` в `/opt/kanban/compose.yml`. База, тома, `.env`, Nginx, whitelist, интеграционные ключи, Redmine и бот не меняются. Миграций нет. Во время сборки прежний Kan работает; при переключении будет короткий перезапуск web.

До переключения: проверка manifest, сборка amd64-образа, актуальный runtime audit (High/Critical блокируют), dump БД с проверкой читаемости, копия Compose и контроль сохранности настроек. После: health/login HTTPS, сохранение закрытого доступа API без токена, окружения и соседних контейнеров. При сбое после переключения возвращается прежний Compose и образ, без восстановления БД поверх новых записей.

Резервная копия и журналы: `/opt/kanban/backups/upgrade-20261007-review-1/` (`build.log`, `image-audit.log`, `switch.log`, `kan.dump`). Повтор успешной установки ничего не меняет.

Проверка пользователем после обновления страницы: кнопка «Ревью карточек» на доске task control; выбранные готовые карточки переходят из Review в Queue, ошибки показываются отдельно. Срок необязателен. Перенос карточки на заголовок колонки должен сохраняться. Операции с рабочими карточками установщик автоматически не выполняет.
