# Смена имени участника: 20261008-member-name-1

Приложение: `d32e20f` в `feat/trisoft-task-control`. Включает прежние исправления массового ревью и переноса на заголовки, а также MCP SDK 1.31.0.

```bash
bash /home/trs_redmine/kanban-release-20261008-member-name-1/deploy/member-name-upgrade-root.sh
```

Запуск из root-консоли сервера Kan. Допустимые текущие образы: `trisoft-kan:20261006-task-control-4-polling`, `trisoft-kan:20261007-invite-link-2`, `trisoft-kan:20261007-review-1`. При неизвестной версии, расхождении сохраненного и работающего окружения или повторе неудачной попытки установщик остановится до переключения.

Плоская установка сохраняется: `/opt/kanban/compose.yml` и `.env`. Меняется только образ `web`; база, тома, env, Nginx/whitelist, Redmine и Telegram-бот не меняются. Миграций нет. Веб работает во время сборки; переключение сопровождается коротким перезапуском.

До переключения: контроль manifest, build amd64, runtime audit (High/Critical блокируют), dump БД с проверкой читаемости, копия Compose и защита от дрейфа конфигурации. После: HTTP/HTTPS health/login, прежний отказ integration API без токена, сохранность окружения и соседних контейнеров. При сбое после переключения возвращается прежний Compose и web-образ; dump не восстанавливается поверх текущих записей. Повтор успешной установки ничего не меняет.

Backup и журналы: `/opt/kanban/backups/upgrade-20261008-member-name-1/` (`build.log`, `image-audit.log`, `switch.log`, `kan.dump`). Ничего из предыдущих попыток не удаляется.

Проверка после обновления страницы: **Участники → ⋯ у активного участника → Изменить имя участника**. Нужны admin и `member:edit`. Имя глобальное для аккаунта; email, ID, назначения и привязки не меняются. Изменение рабочего имени выполняет сам администратор, установщик никого автоматически не переименовывает.
